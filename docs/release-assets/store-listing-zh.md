# Chrome Web Store 商店列表 — 简体中文

英文版主列表见 [`store-listing-en.md`](./store-listing-en.md)。中文是在 Web Store Developer Console 里点 "Add a language" → "Chinese (Simplified)" 后添加的本地化。

## 名称（≤ 75 字符）

```
Snaplex — 把网页的图片、视频帧、截图保存到本地素材库
```

## 简短描述（≤ 132 字符）

```
把网页里的图片、视频帧、区域截图一键保存到 Snaplex 桌面端。完全本地，不上云，不收集任何数据。
```

## 详细描述

```
Snaplex 把浏览器变成一个"一键截图到本机素材库"的工具。配套的 Snaplex 桌面端运行在你的电脑上，扩展把抓到的内容直接送过去 —— 不上云、不发送到任何服务器。

━━━ 能采集什么 ━━━

• 图片 — 右键任意图片 → "保存图片到 Snaplex"
• 视频帧 — 右键播放中的视频 → "保存当前视频帧到 Snaplex"
• 区域截图 — Cmd+Shift+S（Windows/Linux 上是 Ctrl+Shift+S），拖选你想要的区域
• 可视区截图 — 打开 popup → "截取可视区域"

━━━ 为设计师、研究者、所有收集参考素材的人而做 ━━━

• 同一张图重复保存？Snaplex 用内容哈希去重，自动把新的来源 URL 追加进去。
• 每次保存都会记下来源 —— 页面标题、URL、时间。
• 保存成功后页面上会显示一个 toast，不用切到桌面端确认。

━━━ "本地优先"是这个产品的全部立场 ━━━

• 100% 本地。内容只从扩展走到本机的 Snaplex 桌面端。
• 不上云、不做埋点、不发送任何分析数据。
• 不需要账号，不需要登录。
• 开源 — https://github.com/<your-org>/snaplex（发布前替换）

━━━ 需要先装 Snaplex 桌面端 ━━━

这是 Snaplex 桌面端（macOS / Linux）的浏览器配套扩展。请先从 <下载地址> 安装桌面端，再装这个扩展。如果桌面端没启动，popup 会提示你。

━━━ 快捷键 ━━━

• Cmd+Shift+S（mac）/ Ctrl+Shift+S（Windows/Linux）—— 开始区域截图
• 在 chrome://extensions/shortcuts 自定义

━━━ 反馈 ━━━

Bug、需求、反馈：<反馈渠道 URL 或邮箱 — 发布前替换>
```
