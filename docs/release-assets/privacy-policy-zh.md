# Snaplex 浏览器扩展 — 隐私政策

**生效日期：** 2026-05-05
**最近更新：** 2026-05-05

本页面说明 Snaplex 浏览器扩展（下称"本扩展"）如何处理用户数据。本扩展是 **Snaplex 桌面端**的浏览器配套；桌面端运行在用户本机上。

---

## 一句话版

- 本扩展**不收集、不传输、不出售、不共享**任何用户数据到任何远程服务器。
- 你保存的每一张图、每一帧视频画面、每一次区域截图，都只通过 Chrome 本机 Native Messaging API 送到**同一台电脑上的 Snaplex 桌面端**。
- 没有账号、没有登录、没有埋点、没有第三方 SDK。

---

## 本扩展做了什么

当你触发保存动作（右键菜单、快捷键、popup 按钮）时，扩展会：

1. 读取相关像素（你点击的那张图、播放中的视频帧、或你框选的屏幕区域）。
2. 读取当前标签页的 URL 和标题，作为保存内容的来源信息。
3. 通过 Chrome 的 Native Messaging API，把内容字节 + 来源信息交给本机的 **Snaplex 桌面端**。Native Messaging 是操作系统级的本机 IPC，数据不离开你的电脑。

整个数据流就这些。

## 哪些事情**没有**发生

- 本扩展**不**发起任何 HTTP / fetch / WebSocket 请求。我们没有运营任何接收端服务器。
- 本扩展**不**集成任何分析 SDK（没有 Google Analytics、Sentry、Segment、Mixpanel、Amplitude、Firebase）。
- 本扩展**不**包含广告或追踪像素。

## 权限用途

| 权限 | 用途 |
|---|---|
| `nativeMessaging` | 唯一的内容投递通道 —— 把保存内容送到本机的 Snaplex 桌面端进程。 |
| `contextMenus` | 注册"保存到 Snaplex"右键菜单项。 |
| `activeTab` + `scripting` | 注入区域选择 overlay 和页面内 toast，仅在你主动触发保存后才注入。 |
| `tabs` | 读取当前标签页的 URL 和标题，让保存内容记住来源。 |
| `storage` | 保存少量 UI 偏好（最近连接状态、语言）。**不**用于存放任何被采集的图像内容。 |
| `host_permissions: <all_urls>` | 参考素材可能来自任何网站，所以右键菜单和区域截图需要在所有页面上可用。**只有**在你主动触发保存时才会读取页面内容。 |

## 存储与保留

- 被采集的内容存放在你本机磁盘上的 **Snaplex 桌面端素材库**里。扩展自身不保留任何采集内容；交付给桌面端后，内存中的副本即被释放。
- `chrome.storage.local` 中保留极少量（≤ 1 KB）的 UI 偏好。

## 儿童隐私

本扩展不会有意收集任何人（包括 13 岁以下儿童）的数据。

## 第三方

本扩展不向任何第三方分享、出售、出租、转移或披露任何用户数据 —— 因为我们根本就不收集。
